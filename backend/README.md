# SkillSync AI - Cloud Backend (Firebase)

Welcome to the backend folder of **SkillSync AI**!

This project utilizes Google Firebase as a serverless backend-as-a-service (BaaS), eliminating the need for a separate custom backend server. Instead, your frontend communicates securely directly with Firebase services (Authentication, Firestore, and Storage).

---

## 1. Directory Structure

* `firestore.rules`: Rules defining who can read/write data in the Firestore database.
* `storage.rules`: Rules defining upload permissions and size limits for PDF and image notes in Storage.

---

## 2. Database Schema (Firestore Collections)

Here is how the data is structured in your Firestore database:

### `users` Collection
Stores student profile info.
```json
{
  "uid": "USER_ID",
  "email": "student@email.com",
  "displayName": "Student Name",
  "photoURL": "https://lh3.googleusercontent.com/...",
  "streak": 5,
  "lastStudyDate": "2026-05-25",
  "notesCount": 12,
  "quizCount": 8,
  "avgQuizScore": 85,
  "createdAt": "2026-05-20T10:00:00Z"
}
```

### `notes` Collection
Tracks metadata for uploaded study notes.
```json
{
  "id": "NOTE_DOCUMENT_ID",
  "fileName": "Physics_Mechanics.pdf",
  "fileURL": "https://firebasestorage.googleapis.com/...",
  "fileType": "application/pdf",
  "subject": "Physics",
  "summary": "This document covers forces, work, energy, and momentum in Classical Mechanics...",
  "keyTakeaways": ["F = ma", "Work = F * d", "Momentum is conserved in closed systems"],
  "uploadedBy": "USER_ID",
  "uploadDate": "2026-05-25T11:00:00Z"
}
```

### `quizzes` Collection
Tracks dynamic MCQs and scores.
```json
{
  "id": "QUIZ_DOCUMENT_ID",
  "noteId": "NOTE_DOCUMENT_ID",
  "subject": "Physics",
  "questions": [
    {
      "question": "What is the SI unit of force?",
      "options": ["Joule", "Newton", "Watt", "Pascal"],
      "answer": "Newton",
      "type": "mcq"
    }
  ],
  "score": 100,
  "maxScore": 100,
  "userId": "USER_ID",
  "takenAt": "2026-05-25T11:15:00Z"
}
```

### `roadmaps` Collection
Tracks dynamic study paths generated by Gemini.
```json
{
  "id": "ROADMAP_DOCUMENT_ID",
  "goal": "Become MERN Developer in 6 months",
  "weeks": [
    {
      "week": "Week 1",
      "topic": "HTML, CSS and JavaScript Basics",
      "resources": "MDN Docs, FreeCodeCamp",
      "tasks": ["Build personal landing page", "Practice array methods"]
    }
  ],
  "userId": "USER_ID",
  "createdAt": "2026-05-25T11:30:00Z"
}
```

## 3. Deploying Security Rules

To activate the security rules in this folder on your live Firebase dashboard:

1. Install the Firebase CLI tool on your computer:
   ```bash
   npm install -g firebase-tools
   ```
2. Log into your Firebase account:
   ```bash
   firebase login
   ```
3. Initialize the connection in this project root:
   ```bash
   firebase init
   ```
   * Select **Firestore** and **Storage**.
   * Choose your project (`skillsync-9cce2`).
   * Specify `backend/firestore.rules` and `backend/storage.rules` when prompted.
4. Deploy the rules to the cloud:
   ```bash
   firebase deploy --only firestore:rules,storage:rules
   ```
